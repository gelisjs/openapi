# @gelis/openapi

OpenAPI 3.1 contract generation for Gelis.

> Status: implementation in progress.

`@gelis/openapi` is the official optional OpenAPI package for the Gelis
TypeScript backend framework.

The package consumes Gelis application contract snapshots and projects them
into deterministic OpenAPI 3.1 documents.

## Package

```text
npm:    @gelis/openapi
GitHub: gelisjs/openapi
```
