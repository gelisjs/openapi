## Scope

P10-D integrates the post-P9 Gelis contract surface into `@gelis/openapi` without adding request-time OpenAPI work or depending on router internals.

Accepted capabilities include:

- OpenAPI 3.1.2 default output;
- explicit OpenAPI 3.2.0 output;
- QUERY projection;
- custom HTTP method projection;
- fail-closed handling for the `app.all()` pseudo-method;
- post-P9 managed request-body parser/media projection;
- JSON, text, urlencoded, multipart, and arrayBuffer request-body semantics;
- runtime-owned `bodyContentTypes` projection;
- deterministic request-body metadata conflicts;
- multi-media schema occurrence ownership;
- multipart provider-conversion failure reporting;
- preserved single-media synthetic schema resource identity;
- Gelis dependency and Bun lockfile pinned to post-P9 core commit `884e8bed42a40ff69ed1180a155fec6839d26539`.
